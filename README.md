# WitchSpring Civilization VI Mod

一个以《魔女之泉》为主题的《Sid Meier's Civilization VI》自定义文明 Mod，加入文明“魔女之泉”、领袖“派莓”、特色单位“派莓”、特色建筑“魔法缸”，以及围绕训练、成长和神殿庇护展开的独特玩法。

## 简介

人类称派莓为“魔女”，并把她所居住的森林称为“黑暗魔女丛林”。她不知道自己从何而来，也不知道为什么独自生活在森林中，但她开朗、温暖，并拥有纯血神族的魔力与潜力。

本 Mod 将派莓作为《文明 VI》中的可玩领袖与特色单位呈现。她无法像普通文明一样建立宗教，却能以更快的战斗成长速度、独特的训练项目和强力晋升树，在战争与探索中逐渐觉醒真正的魔女之力。

## 主要内容

- 新文明：魔女之泉
- 新领袖：派莓
- 特色单位：派莓
- 特色建筑：魔法缸
- 独特晋升树：魔女晋升路线
- 特色项目：速度训练与魔法训练
- 自定义图标、纹理、领袖背景与历史时刻插图

## 文明特性

### 巴尔特的庇护

魔女之泉文明禁止建立宗教，但所有单位获取经验速度增加 50%。

当已经建立宗教的国家向魔女之泉宣战时，魔女之泉所有城市生产力提高 100%，持续 10 回合。

## 领袖特性

### 魔女的小屋

首都开局直接拥有特色单位派莓和特色建筑魔法缸。

## 特色单位：派莓

派莓是不可生产、不可购买的特殊单位，拥有独特的“魔女”晋升树。她具备战斗、探索和建造能力，可以通过晋升与训练不断提升战斗力和移动力以及特殊能力。

派莓可以：

- 远程攻击
- 改良和清除地块
- 无视区域控制
- 在海上攻击
- 使用传送魔法回到首都
- 通过独特晋升逐步强化自身与整个文明

## 特色建筑：魔法缸

魔法缸是不可建造、不可购买的特色建筑，随领袖特性出现在首都。它用于解锁派莓的训练项目。

通过魔法缸，派莓可以完成速度训练和魔法训练。训练次数达到要求后，会逐步解锁更高级的训练项目。

## 训练项目

魔法缸提供多级训练项目，用于持续强化派莓：

- 游泳：小幅提升派莓移动力
- 冥想：小幅提升派莓力量
- 击打木桩：提升派莓移动力
- 练习制作：提升派莓力量
- 跑步：大幅提升派莓移动力
- 练习魔法：大幅提升派莓力量

## 晋升树特色

派莓拥有专属晋升路线，围绕药剂、修行、魔力护盾、坐骑和四座神殿的庇护展开。

晋升效果包括：

- 提升派莓移动力、战斗力和攻击范围
- 进攻城市和军营时远程攻击效率变为 100%
- 防守时获得额外战斗力
- 所有城市获得额外城墙防御
- 所有单位获得移动力或战斗力加成
- 所有城市生产力提高
- 额外攻击次数
- 攻击后仍可移动
- 对核弹和辐射获得高抗性

## 安装方式

将本仓库内容放入《文明 VI》的本地 Mod 目录，例如：

```text
Documents/My Games/Sid Meier's Civilization VI/Mods/WitchSpring
```

然后在游戏的“额外内容”中启用 `WitchSpring`。

## 兼容性

Mod 文件包含基础游戏、资料片前端配置和 XP1/XP2 相关数据。建议在拥有完整资料片环境的《文明 VI》中使用。

## 开发说明

- `WitchSpring_Units.xml`

- `WitchSpring_Project.xml`
